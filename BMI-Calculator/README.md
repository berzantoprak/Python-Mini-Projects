# BMI Calculator

A simple Body Mass Index (BMI) calculator developed using
Python and Tkinter as part of my Udemy Python course.

## Features
- Calculates BMI based on height and weight.
- Classifies BMI results into different categories.
- Provides a graphical user interface using Tkinter.
- Handles missing and invalid user inputs.
- Displays BMI results with two decimal places.

## Technologies Used
- Python
- Tkinter

## How to Run

1. Make sure Python 3 with Tkinter support is installed.
2. Clone or download this repository.
3. Navigate to the BMI Calculator directory.
4. Run the application:

   python proje.py
