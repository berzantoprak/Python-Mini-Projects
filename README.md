
# Python Mini Projects

A collection of small Python projects developed as part of my Udemy Python programming course.

This repository documents my hands-on learning experience with Python fundamentals, graphical user interfaces, HTTP requests, JSON data processing, and multithreading.

## Projects

| Project | Description | Technologies |
|---------|-------------|--------------|
| [BMI Calculator](BMI-Calculator/) | A desktop application that calculates Body Mass Index and displays BMI categories. | Python, Tkinter |
| Turtle Drawing Project | Geometric drawings and visual experiments using Turtle graphics. | Python, Turtle |
| Tkinter GUI Practice | Exercises covering graphical interface components and user interactions. | Python, Tkinter |
| CryptoCrazyProject | Cryptocurrency data retrieval and experiments with synchronous and threaded HTTP requests. | Python, Requests, Threading |

## Learning Objectives

- Strengthen Python programming fundamentals
- Practice functions and conditional statements
- Build graphical user interfaces
- Retrieve and process JSON data
- Explore threading and execution-time measurements
- Improve code organization and documentation

These projects were developed during my Udemy Python course to reinforce programming concepts through practical exercises.
